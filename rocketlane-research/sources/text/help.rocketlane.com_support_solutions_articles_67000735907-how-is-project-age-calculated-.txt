Project age calculates the duration of time that has passed since a project began.
The project age starts getting calculated when the project status is set to ‘In progress’ and the count stops when the project status is set to ‘Completed’ . This duration helps in tracking the progress and timeline of the project.

Note that the Weekends are included in this calculation.

How to pause the project age?

When you set the project to "In Progress," the project age starts calculating. When the project is marked as "Completed," the project age count stops. If you mark the project as "In Progress" again, the count will continue from where it was left off.

So when you set the project status as completed and then mark as 'In progress' again, the project age count will not begin from 0, it will continue from where it was left off.

For eg, Say the project age is 65 days, and you mark the status of the project as 'Completed'. After some days when you mark the status of the project as 'In progress' again, the project count will start from 65 days and not 0.
