For projects with similar automation needs, you do not need to create the same automation rules repeatedly. You can save an automation rule and apply it across preferred areas in templates.

Save an Automation
To save an automation:

Open the template that has the automation you want to save.

Navigate to the phase or task where the automation has been configured.

Click the Automations tab on the right.

Click the three dots next to the automation rule and select Save automation .

Once the automation is saved, click View saved automation to view or edit it.

Apply saved automations in templates
Rocketlane lets you apply saved automations to templates without recreating the automation rule from scratch.
To apply a saved automation:

Open a project template.

Navigate to the phase or task where the automation rule should be applied.

Click the Automations tab on the right.

Click the New automation button.

From the slider, select and apply the preferred saved automation.

Manage saved automation
To view and access saved automations:

Navigate to Templates .

Click Saved Automations .

Saved automations are categorized into phases, tasks, and forms.
The saved automations list includes:

Automation name: The name of the saved automation.

Applied in: The number of tasks where the saved automation is applied. Click the number to open a slider with the list of tasks. You can click a task in the slider to open the task where the automation runs.

Created on and Created by: The date on which the automation was saved and the user who created it.
Click the three dots next to an automation to Duplicate , Modify , Rename , or Delete it.

Edit Automations
To make changes to a saved automation, click Modify and edit the automation rule.
Note Modifying a saved automation will update it in all places where it has been applied.

Duplicate Automations
If you need to tweak only certain parts of an automation workflow, click Duplicate . This creates a copy of the existing automation rule.
You can edit the duplicated automation and apply it wherever needed.

Delete Automations
To delete a saved automation, click Delete .
Important Deleting a saved automation permanently deletes it from your account. It will also remove the automation from all places where it has been applied.
