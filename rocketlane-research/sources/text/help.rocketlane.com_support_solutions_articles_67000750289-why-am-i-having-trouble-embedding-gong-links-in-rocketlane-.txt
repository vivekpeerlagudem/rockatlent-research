If a Gong link is not loading or shows an error when embedded in Spaces, it is usually because the URL is a "Public Share Link" rather than an "Embeddable Link." Public share links are designed for browser viewing but are blocked from being displayed inside an iframe (the technology used to embed content).

How to resolve the issue
1. Generate the correct Embed Link Instead of copying the URL from your browser or using a standard share link, follow these steps in Gong:

Open the specific Call Page in Gong.

In the top right corner, click Share call .

Select Embed call from the dropdown menu.

The resulting link should contain embedded-call?call-id= (e.g., https://us-42999.app.gong.io/embedded-call?call-id=123... ).

2. Update Permissions Ensure the call's sharing settings are set to "Anyone with the link can view." If the link requires a Gong login, it will not load properly within the Rocketlane interface.
3. Verify Compatibility You can test if your link is "iframe-friendly" using a tool like Iframely .

Paste your Gong link into the tool.

If it returns embeddable code , it will work in Rocketlane.

If it returns a 403 error , the link is still blocked by Gong’s security settings.

Workaround
If you cannot generate an iframe-friendly link, you can create a blank document within your Space and simply paste the Gong share link as a hyperlink. This allows users to click and open the recording in a new tab.
