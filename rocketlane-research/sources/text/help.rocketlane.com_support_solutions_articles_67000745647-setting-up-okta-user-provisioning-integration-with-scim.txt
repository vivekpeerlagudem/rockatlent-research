Rocketlane supports SCIM-based user provisioning through Okta, enabling automated user management for your organization. With this integration, users can be created, updated, or deactivated in Rocketlane directly from Okta, streamlining user lifecycle management.
This article walks you through how to set up and configure Okta SCIM provisioning for Rocketlane.

Note: This is a Beta feature. In case you can't set this up, please contact Rocketlane Support
Overview of SCIM Provisioning Capabilities
The SCIM integration allows you to automate the following user actions:

Create Users : Automatically provision users in Rocketlane when assigned in Okta.

Update Users : Sync user attribute changes (e.g., name, email) in real-time.

Deactivate Users : Automatically remove or disable users in Rocketlane when they are unassigned in Okta.

Prerequisites
SCIM-based user provisioning is currently available to select Rocketlane customers.
To enable this feature for your organization, please contact Rocketlane Support.

Step 1: Set Up the Rocketlane Application in Okta

Log in to your Okta Admin Console .

Navigate to Applications > Browse App Catalog .

Search for Rocketlane in the catalog.

Click Add Integration .

On the setup screen:

Set an appropriate Application Label (e.g., “Rocketlane”).

Click Done to complete the app setup.

Step 2: Generate API Token in Rocketlane
To connect Okta with Rocketlane, you’ll need an API token that authorizes SCIM operations.

Go to Settings in your Rocketlane account.

Scroll to API Settings .

Click Create API Key .

Name the key clearly (e.g., “Okta SCIM Integration”).

Copy the generated API key. You'll use this in Okta setup.

Step 3: Configure SCIM in Okta

Go to the Rocketlane application in Okta.

Select Provisioning from the left-hand panel.

Under Integration , check the box for Enable API Integration .

Enter the following:

SCIM Base URL :
https://<your-subdomain>.api.rocketlane.com/api/scim/v2

Example : If your Rocketlane domain is okta.rocketlane.com , the SCIM Base URL would be
https://okta.api.rocketlane.com/api/scim/v2

API Token : Paste the API key you generated from Rocketlane.

Click Test API Credentials to verify the connection.

Upon success, click Save to confirm and enable the integration.

Step 4: Enable SCIM in Rocketlane
To activate SCIM provisioning:

Contact Rocketlane Support and request SCIM enablement for your workspace.

Once enabled, provisioning actions from Okta will begin syncing with Rocketlane.

Step 5: Test the Integration
After enabling SCIM, verify that provisioning is working correctly:

Assign a user in Okta to the Rocketlane application.

Confirm that the user is created in Rocketlane.

Update user details (e.g., email or name) in Okta and check that changes reflect in Rocketlane.

Unassign or deactivate a user in Okta and verify that the user is deactivated in Rocketlane.
