Nitro Credit Consumption

No article available

As teams use Nitro agents across meetings, projects, and reports, administrators may need visibility into how credits are being consumed and which agent runs account for that usage.
The Nitro credit consumption page provides an account-level view of available credits, monthly usage, and individual agent runs. You can use it to monitor credit consumption, identify usage patterns, and export detailed records for further analysis.
Note This page is available only for accounts with Nitro. To learn more about Nitro, refer to this article .

Understanding Nitro credits
Term Description
Credit The unit used to measure Nitro AI usage. Each time a Nitro agent runs, it consumes credits based on the work performed.
Agent run One complete execution of a Nitro agent, such as generating a meeting summary, detecting signals, or creating an analyst report. A run does not represent each individual AI call made during the execution.
Credit cycle The current period covered by your Nitro credit balance. The Credits used value is measured against this period.
Promotional credits Additional promotional credits available on your account.

When the page becomes available
The Nitro credit consumption page is added to your account automatically when Nitro is enabled. No additional setup is required.

Access Nitro credit consumption
To open the page:

Go to Settings .

Select Nitro .

Click Nitro credit consumption .

View your credit summary
The summary card at the top of the page displays:

Credits used: The number of credits consumed against the credits currently available. Usage is represented through a progress bar.

Promo credits: Any promotional credits available on your account.
Below the summary card, the Credits consumed by month chart displays Nitro credit usage for the previous six months.
This helps administrators compare recent usage and identify changes in credit consumption over time.
[image: Nitro credit consumption page showing credit totals, monthly consumption, and agent run logs]
Review agent runs
The agent runs table lists each completed Nitro agent run on your account.
Each row displays:
Field Description
Run date and time When the agent run occurred.
Run by The user who initiated the run. System-triggered runs display a Nitro tag instead of a user’s name.
Agent The Nitro agent that completed the run.
Credits used The number of credits consumed by that run.
[image: Scrolled Nitro credit consumption log showing historical runs by users and agents] You can filter the table by:

User

Agent

Credit amount
These filters help you review usage for a particular team member, agent, or level of credit consumption.

Export credit consumption data
To export agent run details:

Apply any required filters to the agent runs table.

Click Export at the top of the table.
[image: Export confirmation modal showing CSV processing, email delivery, and Close button] The exported CSV contains the rows matching the currently applied filters.
Depending on the size of the export, the CSV is either downloaded directly or sent to your email address.

Manage access to credit consumption
Access to the page is controlled by the Can access Nitro credit consumption page permission.
By default, this permission is available to:

Account Admins

Super Users
To provide another role with access:

Go to Settings > Permissions .

Open the relevant role.

Enable Can access Nitro credit consumption page .

Save the changes.
[image: Super User role editor showing the Can access Nitro credit consumption page permission] Only users with this permission can access Nitro credit consumption details.

Add or renew Nitro credits
For questions about adding credits, renewing your credit allocation, or managing your Nitro subscription, contact the Rocketlane support team at care@rocketlane.com .
