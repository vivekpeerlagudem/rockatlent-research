Automation Pricing Breakdown
Rocketlane’s automation feature is priced based on the number of runs per user per month. Each plan includes a specific monthly allocation of runs, which determines how many automation actions can successfully complete within that month.

Automation runs by plan
Each plan includes a monthly automation run limit per licensed user.
Plan Automation runs
Essential 50 runs/user/month
Standard 200 runs/user/month
Premium 500 runs/user/month
Enterprise 1000 runs/user/month

Understanding runs/user/month
A run is counted each time an automation successfully completes an action that a user may otherwise have performed manually.
For example, if an automation updates the status of a task, each successful task status update counts as one run.
Note Triggers that match an automation but do not result in an executed action are not counted as runs. For example, if the conditions in an action block are not met and the action does not execute, it does not affect your run limit.

In simple terms, runs/user/month refers to the number of runs allocated to your account based on your plan and the number of user licenses you have purchased.

Example
If your company has purchased 8 licenses on the Premium plan, your total monthly run limit is calculated as:
8 licenses × 500 runs/user/month = 4000 runs per month

This means your account can complete up to 4000 successful automation actions in that month.

Exceeding the limit
If your account exceeds the run limit included in your plan, automations will stop running once the limit is reached.
If you need additional runs, contact the Rocketlane support team to explore options for increasing your automation run limit.
Tip Track your automation usage regularly so you can stay within your plan’s allocated run limit and avoid interruptions.
