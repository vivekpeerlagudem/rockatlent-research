You can add phases to your project by importing a Project Template from the Project Plan.

Go to Create project phase > Import templates .

The Import template dialog box opens.

Add a prefix in case you want to differentiate between pre-existing and imported project phases. The imported project phases will have the prefix added to their names.

Choose a Project template .

Assign a Start date for the project template.

The Due date will be auto-populated based on the total duration of the project template.

Click Add another template + in case you want to add multiple templates.

Click Next: Preview .

You can view all the project phases that will be imported with the project template, along with their respective Start dates . You can expand each project phase and preview the tasks for that phase.

In case Dynamic Conditions are set to the template, only those phases and tasks whose project fields meet the dynamic conditions will be imported.

Click Import to import the project template to your current project.

A new baseline is created upon importing a template in a project. You can view the new baseline from the Timeline view in a project under Baselines .

Upon hovering over the new baseline, you will get a tooltip indicating when this baseline was created and which template import created it.

You can click on the edit icon next to this baseline's name and edit this tooltip further. You can also delete this baseline from the dialog box.

You can rename the baseline to add context about how the old timeline has been recorded before the template was imported to the project.
