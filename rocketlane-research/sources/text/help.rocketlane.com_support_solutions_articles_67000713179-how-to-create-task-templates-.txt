If you are tired of manually recreating repetitive tasks every time you start a new project, Rocketlane is here with a solution. Rather than recreating these tasks from scratch, you can seamlessly incorporate them into your new projects, complete with all the necessary subtasks, assignees, placeholders, properties, and attachments.
In this article

How to save a task template

How to add task template to your project

How? By templatizing these tasks and effortlessly adding them to the necessary phase in your project plan.
Below, we provide a step-by-step guide to walk you through this process.

How to save a task template

Navigate to the Templates section.

Choose the project template containing the task you wish to save.

Click the task that you want to save and select Save as Template from the more actions menu.

Confirm and save the task template.

How to add task template to your project

Select the project you want to add the task template to.

Click the dropdown next to Add task , which is present at the end of each phase.

You will see the Add from task template option in the dropdown. Select it.

You will see a list of all the saved tasks from various templates. Select the task templates that you want to add.

After selecting multiple tasks that you want to add in the phase, add start dates to the tasks by clicking Add start dates .

Once the dates are added, you can add the tasks.

Here, you can see that the tasks are reflected in the phase they are added to. By default, tasks will be added at the end of the phase, and you can reorder them according to your requirements.

This is how Rocketlane's task templates allow you to seamlessly templatize tasks and add them to projects with a few clicks.
