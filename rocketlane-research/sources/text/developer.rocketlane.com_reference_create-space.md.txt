# Create a space

The *Create a space* API allows users to create new spaces in the system for the given project. This endpoint provides a way for developers to add spaces related details, including the  spaceName, project and  privacy of the space. This API returns the created space.

***

> In case any issues arise or further assistance is required, please refer to the [error handling](https://developer.rocketlane.com/docs/http-status-codes) section or reach out to our support team at <care@rocketlane.com> for a prompt resolution.
