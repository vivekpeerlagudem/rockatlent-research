The Operations Insights Report lets you have an insight into the nitty- gritty of how projects, phases and tasks are being executed in your account. You can take a deep dive into each project, phase and task and view trends and charts that help you analyse what works for you and what needs improvement.

This report also draws comparisons between planned versus actual timelines to help you get a better idea of what is being completed ahead of time and what is lagging behind. View trends for specific time periods by applying relevant filters, compare data that has been statistically presented to you and find areas of excellence as well as improvement, all through the Operations Insights Report.

Operational Insights Report: The Tracked vs Planned Tab

This tab gives you an overview of the hours tracked vs the planned effort for templates and tasks in specific.

You can quickly identify how many excess hours have been planned, billable hours tracked, non billable hours tracked and under which category have they been tracked.

Templates

Hours tracked by project: Table

Template
The template used for project creation

Planned Effort
The average number of hours of effort added during project creation

Average Hours Tracked
The average of number of hours tracked for all projects created using the respective template

% of planned effort
Indicates the percentage of planned effort that has been tracked

Excess hours of planned
This indicates the difference between the average planned effort and the average tracked hours

Avg. Billable tracked
Indicates the percentage as well as average number of hours tracked in the billable category

Avg. Non-Billable tracked
Indicates the percentage as well as average number of hours tracked in the non-billable category

Tasks

Hours tracked by tasks: Table

Task
Name of the task

Template
Name of the template to which the task belongs

Phase
Name of the phase to which the task belongs

Planned Effort
The average number of hours of effort added for the task during project creation

Average Hours Tracked
The average of number of hours tracked for the tasks in all projects created using the respective template

% of planned effort
Indicates the percentage of planned effort that has been tracked

Excess hours of planned
This indicates the difference between the average planned effort vs the average tracked hours

Avg. Billable tracked
Indicates the percentage as well as average number of hours tracked in the billable category

Avg. Non-Billable tracked
Indicates the percentage as well as average number of hours tracked in the non-billable category
