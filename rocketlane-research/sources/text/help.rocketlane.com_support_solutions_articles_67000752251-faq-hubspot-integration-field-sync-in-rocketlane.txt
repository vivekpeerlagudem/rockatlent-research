Q1: I'm attempting to establish a one-way integration from Rocketlane Projects to HubSpot Tickets, but a custom dropdown field in Rocketlane isn’t showing up in the Rocketlane-side dropdown of the HubSpot integration UI. What could be the reason?
A: This issue usually arises from a mismatch in field types. To ensure a field is available for syncing, both the Rocketlane field and its corresponding HubSpot field must share the same field type (e.g., Single choice / Multi choice). Moreover, the dropdown options need to match in case on both ends. Validate that the field type and option values are exactly the same in both platforms, and the field should then appear in the integration UI.

Q2: Why isn't a User-type field in Rocketlane syncing to HubSpot as anticipated?
A: Rocketlane can only synchronize fields that have matching field types. If a field in Rocketlane is a User-type (single-select), the related field in HubSpot must also be a user-type field — it cannot be a standard single-select text field. If the HubSpot field is set up as plain text or a dropdown field, the sync won't function as intended. Make sure the HubSpot field is designated as a user-type field to facilitate proper syncing.

Q3: Is it possible to sync the Project Notes or Project Status fields from Rocketlane to HubSpot?
A: Yes, these fields can be set up for synchronization within the HubSpot integration's Fields Sync tab. Go to the HubSpot integration settings, access the Fields Sync section, and map the applicable Rocketlane project fields (like Project Status or Project Notes) to their respective HubSpot fields. Ensure the field types are compatible on both sides for the synchronization to work effectively.

Q4: Can I utilize automation in Rocketlane to transfer the value from a User-type field into a plain text field so that I can sync it to HubSpot as text-to-text?
A: Absolutely! Rocketlane's built-in automations can facilitate copying data from one field to another. You can create an automation that reads the value from a User-type field and writes it into a different plain text field. Once the data is in a text field, it can then be synchronized to HubSpot as a text-to-text mapping, circumventing the user-to-user field type requirement.

Q5: How is the Project Owner field synchronized between Rocketlane and HubSpot?
A: The Project Owner is generally configured and synchronized through a HubSpot automation rather than a straightforward field mapping. When a deal is finalized and a project is initiated in Rocketlane via the integration, automation can be arranged to assign the appropriate owner. The "Project Owner" field in Rocketlane is a User-type field, which necessitates a user-type field counterpart in HubSpot for direct field synchronization to function.
