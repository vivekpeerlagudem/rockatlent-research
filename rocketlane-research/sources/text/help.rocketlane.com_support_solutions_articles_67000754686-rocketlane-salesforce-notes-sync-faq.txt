Field Configuration & Mapping

Q: Why can't I find the Rocketlane "Project Notes" field in the field sync configuration to map it to Salesforce?
A: The Project Notes field in Rocketlane is a nested/structured field that allows multiple note entries to be created within it. Because of this, it cannot be mapped directly through the standard field sync configuration like a plain text field can.

Q: Is there an alternative way to sync Rocketlane Notes data to Salesforce if direct field mapping isn't supported?
A: Yes. You can link the Notes field in Rocketlane to a Salesforce object (e.g., an Opportunity or a custom object). This will push the text entered in the Rocketlane Notes field as a note on that corresponding Salesforce record.

Q: Which Salesforce Notes object should I use? The standard Notes or Enhanced Notes?
A: Salesforce currently recommends using Enhanced Notes , which is the newer version. You should set up Enhanced Notes in Salesforce per Salesforce's admin setup guidelines before configuring the sync.

Q: Can I sync Notes to a custom Salesforce object, or does it have to be the Opportunity object?
A: You can sync to a custom object and it is not limited to the Opportunity object.

Behaviour & Historical Data

Q: Will the sync apply to previously created/historical notes, or only new ones going forward?
A: The sync applies only to updates going forward , not historical data. In a bidirectional sync, the system relies on the "latest update" to determine the source of truth, so it cannot determine which side is authoritative for pre-existing records.

Q: Can a one-way (RL → SFDC) sync push historical notes data?
A : Force sync is not supported for Notes-type fields, so historical data cannot be pushed via a one-way sync either.

Troubleshooting & Data Export

Q: The notes sync isn't working and I see errors. What should I check?
A: Check the Error Logs tab in Rocketlane for specific details. Errors are commonly permission-related. Verify that the Salesforce integration user has:

Access to the relevant object with Read/Create/Edit permissions.

Access to the specific record being referenced.

Access to any related lookup field records.

Q: Can I export Rocketlane Notes data via the UI or API to use externally (e.g., for AI analysis)?
A: A self-serve export via the UI or API is not currently available for Notes data. However, Rocketlane support can provide a one-time data export of the Notes field values as a CSV, which you can then manually import into Salesforce or use for other purposes.
