Form triggers monitor events that happen within forms, such as new form responses and form approval responses. You can use these triggers to automate follow-up actions when customers or internal teams submit or approve form responses.
Form triggers can be configured at the template level for projects that use specific templates. To set them up, open a project template, select a form inside the template, and add an automation.
Form triggers include all task triggers, along with form-specific triggers.
In this article

New form response

New form response
The New form response trigger runs when a new response is submitted for a form.
You can use this trigger to start workflows based on the submitted response.
For example, when a new form response is received and the selected use case is Onboarding , you can import the onboarding project template.
You can use this trigger under Template automations by navigating to Templates > Project template > Select any form > Add automation .

New form approval response
The New form approval response trigger runs when an approval response is received for a submitted form response.
You can use this trigger to notify stakeholders or run follow-up actions after a form response is approved.
For example, when a new form response is approved, you can send an email to project members.
This trigger can be used in both Global Automations and Template Automations .
