A: To achieve a clear, consolidated view of projects grouped by the phase they are currently in, in your dashboards, use the "Current Phase" field for grouping.
Here's how to set it up:

Go to: Dashboards > New Dashboard > Chart

In the Group By tab, select Current Phase .

By using the Current Phase's normalized display name , all projects currently in that phase (e.g., "Design") will automatically consolidate into a single row on your chart. Furthermore, clicking on that unified row will instantly show you a list of all the individual projects that contribute to that phase count.
