This help article lists the ways to create a new task and how to execute creating a task successfully.

Ways to Create a New Task

From Project Plan

From Project Tasks list

The new task hotkey N

From Project Plan

Go to Projects and select the project you want to add a task to.

In case the project has no phases, you have to create a phase to add a task. Click Create phase .

To add a task to an already existing phase, click Add Task at the end of each phase.

Add a task name , choose assignees , set a due date or set a start and end date , add a task description , and click Create .

The task will be added to the phase.

From Project Tasks List

Go to Projects and select the project you want to add a task to.

Go to the List tab.

Click Add new task .

Add a Task name and press Enter .

The task will be added to the list.

You can add Assignee, Priority, Start Date, Due Date, Effort, Process, At risk, Completed at, Responsible, Created by, Created at, Jira issue, Task type, Budget, Product Board URL and Project Phase to the task.
Note Only Account admins will have access to edit the Completed At date of the task.

From the New Task Hotkey

Press the alphabet key N while you are logged in to Rocketlane from anywhere in the product.

Type a Task name for the task and choose a project to assign to the task.

Post adding a project , you can add Assignees , Due date , and Task Description .

The Create button has a drop-down with two options:

Create and Open: Allows you to create a public task and open the task details.

Create as Private: Allows you to create a private task and open the task details.

Choose an option from the two and a new task will be created and will open.

Adding Bulk Tasks
You can bulk add a list of tasks from the List view in a Project .

Create a list of tasks that you want to add to your project. Select the list and copy it to clipboard.

Go to Projects and select the project you want to add a task to.

Go to the List tab and click Add new task . Paste the list of tasks you want to add.

A list of new tasks will be added to the Tasks List in the project.

You can add Assignee, Priority, Start Date, Due Date, Effort, Process, At risk, Completed at, Responsible, Created by, Created at, Jira issue, Task type, Budget, Product Board URL and Project Phase to the tasks.

How To Add a Spotlight Task
To draw attention to a specific task or prioritize it, you can use the Spotlight feature in Rocketlane. For instance, if there's a hand-off form that your team needs to fill out to move a project from one team to another, you can spotlight it to ensure that the task is given top priority.
To do this:

Select the task you want to highlight for your team.

Click the sunlight icon within the task.

Label the spotlight to convey your message.

Click Add to spotlight the task.
