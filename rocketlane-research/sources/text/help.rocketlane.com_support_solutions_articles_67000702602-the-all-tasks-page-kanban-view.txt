The Kanban view on the All Tasks page allows you to have a global view of all tasks across all projects in a board format.
You can edit the task properties based on which the rows and columns are grouped.
You can click on a task and edit task properties from the task pane that opens.
You can also have custom views based on task status, assignee, due date, and other fields. Choose from default view options or create custom views using filters. You can filter tasks based on your preferences and save the filtered list as a shared or private view.

Adjusting Row and Column Settings
From the top navigation bar, you can choose which task fields you want to use to group your rows and columns.
You can adjust these from the top navigation bar.

Row Options
You can categorize the rows using the following default task field options:

None

Assignee

Priority

Project

Project Phase
Note You can add custom task fields that have the field type value set as Single choice .

Column Options
You can categorize the columns using the following default task field options:

Assignee

Due Date

Priority

Status

Filters and Views
To read more about how to apply filters and save views, click here .

Hide empty rows
The Hide empty rows option allows you to get a clearer view of your tasks by removing empty rows.
