Task statuses show the current state of a task and make it easier to track progress across a project. Rocketlane includes the following default task statuses:

To Do

In Progress

Completed

Blocked
You can also create custom task statuses to match the stages and terminology your team uses. Each custom status belongs to one of the default status groups, which determines how Rocketlane treats tasks assigned that status.

Add a custom task status

Click your profile icon, then select Settings .

Under Fields , select Task fields .

Next to the Status field, open More actions , then select Edit .

In Edit task field , under Choices , select Add option .

Enter a name for the status and select a color.

From the dropdown next to the status name, choose the group the status belongs to: Todo , In Progress , Completed , or Blocked . Rocketlane treats the custom status according to the group you select. For example, if you create an Awaiting Sign-off status and place it in the Completed group, tasks with that status are treated as completed.

To reorder statuses, drag the handle to the left of a status.

Select Save .

Note Status names must be unique. If you enter a name that already exists, Rocketlane displays This status already exists . Some default statuses cannot be renamed or removed. The remove option is available only for statuses that can be deleted.
