# Add field Option

Add an option to a `SINGLE_CHOICE` or `MULTIPLE_CHOICE` field, or a tag to a `NOTE` field. For NOTE fields, the option is stored as a tag and returned as a fieldOption.

The *Add field option* API allows users to create a new option for a `SINGLE_CHOICE` or `MULTIPLE_CHOICE` field, or a tag for a `NOTE` field, using the `fieldId`. For `NOTE` fields, the option is stored as a tag and returned as a `fieldOption`. This endpoint provides a way for developers to add field option details, including the option label as well as the option color.

> 📘 New option will append to the existing ones upon addition.

***
