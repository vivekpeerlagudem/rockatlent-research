When you update a Form Template's sharing setting to Anyone with the link , the change applies only to form tasks created after the update.
Form tasks inherit the sharing permissions that were active on the form template at the time the task was created. Updating a form template does not retroactively change the access permissions of existing form tasks.

Why existing form links still ask for login
If a form task was created before the template's sharing setting was changed, that task continues to use the earlier permission setting. This means its form link may still ask users to sign in, even if the form template is now set to Anyone with the link .
To apply the updated sharing setting, create a new form task from the updated template and share the newly generated link.
Note Updating a Form Template's sharing setting does not update links for form tasks that already exist.

Resolve the issue

Go to Templates > Forms .

Open the required form template.

Under Form Settings , verify that Sharing is set to Anyone with the link .

Save the template, if needed.

Go to the project where the form should be used.

Add or create a new task using that form template.

Copy and share the newly generated form link from the new form task.

Verify public link access

Verify the form template setting: Go to Templates > Forms , open the form template, and confirm that Sharing is set to Anyone with the link .

Generate a new form task: Add a new task using this form template within your project.

Test the public link: Copy the public link from the new form task and open it in a private or incognito browser window.
If the sharing setting is applied correctly, the web form opens immediately without prompting for a Rocketlane login.
