How to Add and Manage Phase Dependencies in Rocketlane?

No article available

Phase Dependencies allow you to define relationships between phases that are dependent on each other. It is a handy feature for collaborative teams to mark the order in which activities need to be performed.

Rocketlane notifies you about dependent phases so that you can schedule your phases and tasks accordingly.

Note: Rocketlane allows you to have finish to start phase dependencies. This means that dependent phases are meant to start after the dependent phase is marked as Complete .

Adding Phase Dependencies using the Timeline view

Go to Projects and select the project where you want to add Phase dependencies.

Go to the Timeline view.

Drag and drop the cursor from the end bubble of the predecessor phase till the beginning bubble of the successor phase .

A tooltip will indicate if the dependency you want to create is valid or not. The dependency will be created only when it is valid i.e. end to start dependency.

Note: Dates for the successor phase will be auto adjusted according to the dates of the dependent tasks as and when you keep creating phase dependencies.

Multiple Phase Dependencies from the Timeline View

You can add multiple phase dependencies for a given phase from the timeline view.

From the Timeline view, drag and drop the cursor from the end bubble of the predecessor phase till the beginning bubble of the successor phase .

Deleting Phase Dependencies

You can delete a Phase dependency from the timeline view by clicking on it.

A dialog box will ask you to confirm the deletion. Click OK .
