If your automated emails not being sent out, please follow these instructions:

Determine the Level of Automation:

Is the automation set at the template level or globally?

If Template Level:

Verify if the trigger, conditions, and logic (AND/OR) are relevant in the template where you’ve set the automation up.

Check if the “To” section of the email is correctly entered.

After checking for these, please check if the project where you expect the e-mail to be triggered from has the task/phase/sub-task you’ve set up the automation in, is present (Eg: You have two templates with similar names, or two tasks with a similar name, calling the wrong one within your project might be causing the confusion)

If Global Level:

Ensure the rule is triggered correctly (on all projects, phases, tasks, or forms).

Verify the trigger action, conditions, and logic (AND/OR) are relevant.

Check if the “To” section of the email is correctly entered.

If Everything is Correct but Email is Not Triggering:

Provide the following details via our chat or write to care@rocketlane.com:

Link to the automation or template level task/phase where it is set.

Project/phase/task where you expect the trigger to occur.
