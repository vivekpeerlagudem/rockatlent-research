How to Create a New Blank Rocketlane Doc?

No article available

Need to start a new document from scratch? Rocketlane Spaces give you a flexible canvas to document project details, share updates, and collaborate with team members and clients. Use this step-by-step guide to create a new blank document in your project space:

Click the Projects tab from the left navigation bar.

Choose the project you want to add a document to.

Click the Spaces tab.

From the left navigation bar, go to the space that you want to add the document to and click Add private file or Add shared file .

Click Blank document .

Your blank document is ready for you to edit.
