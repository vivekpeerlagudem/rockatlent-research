The task fields in Rocketlane are attributes that help define tasks. There are some default fields, and you can add custom fields to your account as well.

How to access and create Task Fields in Your Rocketlane Account

Go to Settings .

Go to Task fields .

You will see a list of all the default and custom task fields added to your account.

You can view the field type and whether each field has been enabled. Enabling a field determines whether the task field can be viewed in your projects.

How to create a new Task Field section in Your Rocketlane Account
Task fields are divided into sections for easier categorisation. You can create your own custom section to add task fields related to your organization's needs.

Click New Section from the top-right side of the screen.

Add a name for the new section and click the green checkbox button to save the section.

A new section will be added for the task fields. You can add new fields to this section. This list displays the field description, field type, and status.

How to add a new Task Field in Your Rocketlane Account

Click the New field icon from the top-right side of the screen.

From the New task field dialog box, add a field name, choose the field type and section, and add a description if needed. The description will show as a tooltip. Click Save after adding the details for the new task field.
