# Delete project by Id

Using the *Delete project by Id*  API, users can delete a particular project from the system using its unique Id (`projectId`). When a project is no longer required or is obsolete, developers can permanently delete it using this endpoint.  Upon successful deletion, *`HTTP status 204`- no content* is returned as a response with no response body.

> 📘 Note
>
> Only Admins, Super Users and Project Owners can delete a project.

> 🚧 Warning
>
> Once the project is deleted, there's no option to retrieve it back. If you need to revive the project again, please use the [Archive project by Id](https://developer.rocketlane.com/v1.0/reference/archiveproject) API.
>
> When a project is archived, it becomes dormant and is removed from the project list, maintaining all of its details and historical data but signalling that it is no longer an active project.

***

> In case any issues arise or further assistance is required, please refer to the [error handling](https://developer.rocketlane.com/docs/http-status-codes) section or reach out to our support team at <care@rocketlane.com> for a prompt resolution.
