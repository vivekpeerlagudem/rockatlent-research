# Create a task

The *Create a task* API allows users to create new tasks in the system for the given project. This endpoint provides a way for developers to add task details, including task name, dates, assignees, and any custom fields associated with the task.

To customise the response, utilise the `includeFields` parameter and it will return the created project in the response body.

***

> In case any issues arise or further assistance is required, please refer to the [error handling](https://developer.rocketlane.com/docs/http-status-codes) section or reach out to our support team at <care@rocketlane.com> for a prompt resolution.
