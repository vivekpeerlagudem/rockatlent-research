The List view on the All Tasks page allows you to have a global view of all tasks across all projects in a list format. You can read or edit task properties like project, assignee, start date, due date, and more.
You can also view custom task lists based on task status, assignee, due date, and other fields. Choose from default view options or create custom views using filters.
You can filter tasks based on your preferences and save the filtered list as a shared or private view.

List View: Task fields
Each task has associated properties called task fields. Here is the list of task fields available in the All Tasks List view :

Project

Assignee

Priority

Start Date

Due Date

Effort

Progress

At Risk

Completed At

Responsible

Created By

Created At

Billable

Category
Note There is a count of the total number of tasks at the bottom of the page.

Performing Bulk Actions with Tasks
You can click the checkbox on the left of each task to select it.
On selecting a task, the task selection dialog box appears on the left side of the screen.
You can edit the following properties for tasks in bulk:

Set Status

Set Start Date

Set Due Date

Shift Dates

Add Assignee

Reassign to

Delete

Filters and Views
To read more about how to apply filters and save views, click here .

Exporting Task Lists as CSVs
Click the Export icon from the top-right corner of the screen.
