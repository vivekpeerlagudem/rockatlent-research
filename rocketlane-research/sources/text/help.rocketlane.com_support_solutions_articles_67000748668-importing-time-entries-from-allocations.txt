If you've already allocated hours to projects in Rocketlane, you can import them directly into your timesheet instead of entering them manually.
How it works

Go to the Timesheets page

Click Add Row > Import from allocations

Review the suggested time entries that appear based on your allocations for the week

Edit any details you need to:

Add or edit work descriptions (auto-populated if the allocation was for a specific task or phase)

Select a category

Mark as billable or non-billable

Add notes

Update any other custom fields your organization has set up

Add the entries to your timesheet

Things to note

You won't be able to log time if certain settings are enabled, such as

Restricting time tracking if the project is completed / cancelled / in other restricted statuses

Restricting time tracking if you are not part of the project.

If the time period has been locked by an admin

Some fields may be read-only based on your permissions. Contact your admin if you need to edit a locked field
