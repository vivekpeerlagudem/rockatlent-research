The Operations Insights Report lets you have an insight into the nitty- gritty of how projects, phases and tasks are being executed in your account. You can take a deep dive into each project, phase and task and view trends and charts that help you analyse what works for you and what needs improvement.

This report also draws comparisons between planned versus actual timelines to help you get a better idea of what is being completed ahead of time and what is lagging behind. View trends for specific time periods by applying relevant filters, compare data that has been statistically presented to you and find areas of excellence as well as improvement, all through the Operations Insights Report.

Operations Insights Report: The Overview Tab

This tab gives you an overview of the planned vs actual completion time of the projects that have been created using templates and also for their respective phases and tasks. You can quickly identify both on-time completions and completion delays by glancing at the charts, graphs and tables in this tab.

Filter

Lets you filter projects or tasks or phases based on project fields

Projects Created Filter

This filter lets you analyse the people performance based on time frames so that you can specifically monitor performances for specific time periods.

The ' Custom' option lets you add custom ' Start date' and ' Due date' so that you can analyse people performance for specific dates.

Templates

On-time completion performance: Graph

This graph displays an overview of projects completed on time vs delayed for each template for the selected time period.

The x-axis represents the templates that have been used for creating projects during the selected time period and the y-axis represents the completion performance in percentage.

The bars in green indicate on-time completion and the bars in red indicate a delay in project completion.

All Template Durations: Table

This table lets you compare project completion time on the basis of templates used to create the projects.

Template
Name of the templates used for project creation

Number of Projects
Number of projects created using that template

Planned Duration
The duration of the template used

Average Completion Time
The average of all the completion times of the projects created using the template

50th %ile Completion time
Indicates that 50% of all projects created using the template have been completed on or before this time duration

90th %ile Completion time
Indicates that 90% of all projects created using the template have been completed on or before this time duration

% projects Completed late
The percentage of projects that have been completed later than the planned duration

CSAT
The average CSAT ratings from the projects created using the template

Phases

Most delayed phases: Graph

This graph displays the top five phases that have been delayed the most vs the average deviation (in days) from the planned duration of the phase.

The x-axis represents the phases from templates that have been used for creating projects during the selected time period and the y-axis represents the average deviation from the planned duration.

Phases Completed Early: Graph

Top five phases that have been completed earlier than the planned duration vs the average deviation from the planned duration of the phase

The x-axis represents the phases from templates that have been used for creating projects during the selected time period and the y-axis represents the average deviation from the planned duration.
