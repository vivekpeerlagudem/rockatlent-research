How can I filter or report on Rocketlane projects that are missing a linked Salesforce project ID?

No article available

As Rocketlane does not natively offer a filter for the raw Salesforce Object ID/URL, use the following setup:

Map a Custom Field: Create a custom project field in Rocketlane and map it to the Salesforce Object ID field in your Salesforce integration settings. You can now use this custom field in Custom Reports or the Project List View to filter by Is Empty .

Handle Deleted SFDC Projects: If a project is deleted in Salesforce, its ID will not automatically clear in Rocketlane. To resolve this:

Create a custom Yes/No field named SFDC Project Deleted .

Build an automation in Rocketlane: Trigger: When SFDC Project Deleted is updated to Yes → Action: Clear value for the custom SFDC Object ID field.
