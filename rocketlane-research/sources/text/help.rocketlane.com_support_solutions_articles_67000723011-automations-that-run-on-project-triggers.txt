Project triggers monitor events across projects and help automate workflows that keep projects moving smoothly. You can use project triggers to respond to key project events, such as project creation, field updates, customer invitations, placeholder resolution, archiving, and deletion.
Project triggers can be configured under Global Automations .

Navigate to Avatar > Settings > Advanced > Automations .

Project created
The Project created trigger runs when a new project is created.
You can use this trigger to automatically apply templates, notify team members, or set up follow-up actions based on project details.
For example, when a project is created with ARR greater than $100K, you can import the Simple Onboarding template.
You can also add multiple action blocks for different ARR ranges. For example:

If ARR is greater than $300K, import the Mid-market Onboarding template.

If ARR is greater than $500K, import the Enterprise template.

Field is updated
The Field is updated trigger runs when a project field is updated.
You can use this trigger to notify stakeholders, update related fields, or take action when a project reaches a specific state.
For example, when the project status is updated to Blocked , you can notify the project owner and then archive the project.

Customer invited
The Customer invited trigger runs when a customer is invited to a project.
You can use this trigger to start customer-facing workflows after inviting customers to the project.
For example, when a customer is invited, you can send welcome emails and update the project status to In Progress .

Placeholder resolved
The Placeholder resolved trigger runs when a placeholder is replaced with an actual value, such as a customer name or team member.
You can use this trigger to update project data or run follow-up actions after placeholder values are resolved.

Customer placeholder resolved
For example, when a customer placeholder is resolved, you can replace the placeholder value with the actual customer in the project list field and send welcome emails.

Team member placeholder resolved
For example, when a team member placeholder is resolved, you can turn soft allocations into hard allocations.

Project archived
The Project archived trigger runs when a project is archived.
You can use this trigger to notify project members or run closure-related workflows.
For example, when a project is archived, you can notify project members through Slack and email.

Project deleted
The Project deleted trigger runs when a project is deleted.
You can use this trigger to notify relevant stakeholders when a project is removed.
For example, when a project is deleted, you can notify project members through Slack and in-app notifications.
