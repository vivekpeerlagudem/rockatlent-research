# D1 evidence ledger: semantic verification

Verifier: an independent check that used only local files (`sources/text/*`, `sources/trim.sh`, `analysis/api-*.csv`). I did no web research. For each row I re-read the cited article body in context, not only the quoted span. For every UNKNOWN row and every "not documented" claim, I grepped the article bodies of all 410 saved help-centre files.

## Cross-row contradictions and tensions

1. **D1-012 / D1-013 vs Sheets "Task link" column.** D1-013's note says there is no documented task-link mechanism. HC-67000748152 documents a Task link column type.
2. **D1-012 vs D1-053.** D1-012 implies the help centre's only RAID representation is Sheets, while D1-053 documents a Nitro Record Block for "a running risks log or open issues list".
3. **D1-075 vs D1-076.** D1-075 states that project and phase webhook events exist. D1-076 calls this inconsistent, and the setup guide says only task triggers are currently supported.
4. **D1-014 and D1-073 vs DEV-reference_companies.** Both rely on "all 79 endpoints", but the Companies reference points to an Addresses API that is not in the inventory.
5. **D1-085 vs D1-036.** D1-036 says "typically depends on your CRM integrations", and D1-085 drops "typically".
6. **D1-028 / D1-029 / D1-045.** The Signals article describes account linking by project membership and Account domain fields, which differs from the three-step exact matching article. D1-029's inconsistency set should include it.
7. **D1-033 vs HC-67000755648.** The matching article says matched meetings appear in "relevant project context", while D1-033 (from other articles) says meetings are not associated with projects by default.
8. **D1-058 vs HC-67000755370.** The credits article lists "creating an analyst report" as a Nitro agent run.

**Patterns:**
- **Qualifiers dropped.** Six of the OVERSTATED rows leave out a qualifier that is in the source: "currently", "by default", "typically", "solely for recording ingestion", or "when enabled".
- **Absence claims graded CONFIRMED.** All three WRONG GRADE rows treat an absence ("no RAID object", "no API resource", "no task creation") as if docs stated it.
- **Notes and unknowns contradicted by saved docs.** In all five CONTRADICTED rows the cited fact is fine, but the "not documented" note or the unknown is answered by a saved document:
  - D1-013: the Task link column.
  - D1-058: the analyst report.
  - D1-077: Basic Auth for webhooks.
  - D1-095: the AWS Cognito migration.
  - D1-097: deletion of meeting and email pages.
- **Unknowns partly answered in SUPPORTED rows.** The D1-073 unknown has a lead (a 100 requests/minute limit, stated for UI bulk updates). D1-025 and D1-096 can each be narrowed with documented details.
